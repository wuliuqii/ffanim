# ffanim 重构计划（v0.4.0 后 · 预览器前）

> 状态：R0/R2/R1 已完成（含 R1 方向变更，见 §R1）；下一步 R3（画布参数化）→ 预览器循环/seek。
> 基线 = v0.4.0 tag（commit 72b29ec）。
> 目标：在开发预览器循环/seek 功能之前，清偿影响长期演进的技术债，
> 并为预览器的无缝集成（不同画布尺寸、场景复用、UI 主题化）铺平接口。

## 0. 现状盘点（2026-10-14 实测）

### 0.1 examples 现状与 manim 对标

| | manim 社区版 | ffanim 现状 |
|---|---|---|
| 数量 | gallery 按主题分册（入门/动画词汇/公式/图表…） | 仅 2 个：`fourier.rs`（227 行端到端创作）、`media.rs`（SVG/图片） |
| 组织 | 每示例一个 Scene 子类 + `construct()`，可独立运行 | 每示例一个 `fn main`，自建 Timeline |
| 入门梯度 | `SquareToCircle` 级 10 行入门示例缺失 | 最简单示例也要读完 90+ 行 |

**缺口评估**：缺「入门示例 → 动画词汇 → 公式 → 数据展示」的梯度；
`table`/`TableOptions`/`TableSpec` 三个新公开项零示例引用（api_coverage
门禁红灯的直接原因）。建议补 4 个（见 R4）。

### 0.2 out/ 产物生成流程（文档化）

`out/` 整目录 gitignore（`*.mp4` 亦全局忽略），全部为**开发验收产物，不入库**。
三类生成路径（R1 后：CLI 场景绑定子命令已删，examples 直跑为主路径）：

| 来源 | 触发 | 产物 |
|---|---|---|
| ① examples 直跑（主路径） | `cargo run -p ffanim --example basic -- demo_anim`（argv 寻址，缺省全渲染） | 18 个 `*_demo.mp4`（out/<场景名>.mp4） |
| ② gally 批量 | `just book`（= ffanim-gally 生成书源 + mdbook build） | 全量场景 mp4 + `docs/book/` 示例书（视频+源码） |
| ③ justfile 配方 | `just demo` / `just demo-formula` / `just fourier` | 指向 ① 的快捷方式 + `out/fourier.mp4` |

测试探针产物（`test_audio.wav`/`long_audio.wav`/`scenes_arrow_*.mp4`）来自
编码/音频单测与早期探针，同属一次性产物。

**依赖关系**：系统 ffmpeg（PATH 可见）→ ffanim-cli → 主题 JSON
（`themes/default.json`）→ 字体（`find_cjk_font` 自动查找，env
`FFANIM_CJK_FONT` 可覆盖）。**配置参数**：`RenderArgs`（fps/quality
ql·qm·qh·qk/segments/audio/section/theme/out），画质预设覆盖 fps 并
定分辨率与 CRF。**缺口**：①类路径靠记忆敲命令，无 `just` 配方固化，
无清理配方（`clean-out`）。

### R1 · 场景库迁移 examples + CLI 瘦身（P1，M，预览器前置）✅ 已完成（方向变更）

  - 18 个内置场景迁至 `crates/ffanim/examples/` 四文件：`basic.rs`（8）/

- **验收**：18 场景 timeline JSON 与基线 md5 逐一比对 18/18 一致（零语义

## 2. 实施顺序

```
R0 ✅ → R2 ✅ → R1 ✅(方向变更:examples 迁移) → R3(画布参数化)
→ R4(examples 梯度) → R5(out 固化) → R6(preview 补强) → 预览器循环/seek
```

R0/R2/R1 互不阻塞可穿插（三项均已完成）；**R3 必须先于预览器开发**（预览
窗口尺寸自适应依赖 Canvas2D 传导）；R4 的 data_table 与 R0 合并执行可少走
一遍。R1 迁移后 18 个官方示例已就位，R4 剩余目标收窄为「入门梯度」补缺
（getting_started 级 15 行示例）。

## 3. 总验收标准

1. `just ci` 全绿（fmt + clippy -D warnings + test + api_coverage）；
2. 行为不变证明：17 场景 `timeline --json` 与基线逐字段一致 + 关键 demo
   末帧像素探针一致；
3. 960/540 与主题色反例 grep 归零；
4. examples ≥ 6 个且各自独立出片，形成入门梯度；
5. out/ 产物路径全部有 just 配方或文档锚点。

## 4. 明确不做（防蔓延）

- 不引入新依赖；不动两阶段时间轴模型与编译期求值架构；
- 不为拆而拆：eval.rs 965 行职责单一，保持现状；
- CLI 依赖 7 内部 crate 属编排层合理设计，仅补架构注释说明，不改依赖结构。
