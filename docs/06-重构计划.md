# ffanim 重构计划（v0.4.0 后 · 预览器前）

> 状态：规划中。基线 = v0.4.0 tag（commit 72b29ec）。
> 目标：在开发预览器循环/seek 功能之前，清偿影响长期演进的技术债，
> 并为预览器的无缝集成（不同画布尺寸、场景复用、UI 主题化）铺平接口。

## 0. 现状盘点（2026-10-14 实测）

### 0.1 examples 现状与 manim 对标

| | manim 社区版 | ffanim 现状 |
|---|---|---|
| 数量 | gallery 按主题分册（入门/动画词汇/公式/图表…） | 仅 2 个：`fourier.rs`（227 行端到端创作）、`media.rs`（SVG/图片） |
| 组织 | 每示例一个 Scene 子类 + `construct()`，可独立运行 | 每示例一个 `fn main`，自建 Timeline |
| 入门梯度 | `SquareToCircle` 级 10 行入门示例缺失 | 最简单示例也要读完 90+ 行 |

**缺口评估**：缺「入门示例 → 动画词汇 → 公式 → 数据展示」的梯度；
`table`/`TableOptions`/`TableSpec` 三个新公开项零示例引用（api_coverage
门禁红灯的直接原因）。建议补 4 个（见 R4）。

### 0.2 out/ 产物生成流程（文档化）

`out/` 整目录 gitignore（`*.mp4` 亦全局忽略），全部为**开发验收产物，不入库**。
三类生成路径：

| 来源 | 触发 | 产物 |
|---|---|---|
| ① CLI 手工渲染（开发验收） | `./target/debug/ffanim render -s <场景> -o out/<场景>.mp4` | 17 个 `*_demo.mp4` + 画质三格式（`demo_anim_ql.gif`/`qm.webm`/`qh.mp4`）+ `sine_voice.mp4` |
| ② justfile 配方 | `just demo` / `just demo-formula` / `just fourier` | `out/demo.mp4`、`out/formula_demo.mp4`、`out/fourier.mp4` + strip/onion PNG |
| ③ examples 直跑 | `cargo run -p ffanim --example media` | `out/media.mp4` |

测试探针产物（`test_audio.wav`/`long_audio.wav`/`scenes_arrow_*.mp4`）来自
编码/音频单测与早期探针，同属一次性产物。

**依赖关系**：系统 ffmpeg（PATH 可见）→ ffanim-cli → 主题 JSON
（`themes/default.json`）→ 字体（`find_cjk_font` 自动查找，env
`FFANIM_CJK_FONT` 可覆盖）。**配置参数**：`RenderArgs`（fps/quality
ql·qm·qh·qk/segments/audio/section/theme/out），画质预设覆盖 fps 并
定分辨率与 CRF。**缺口**：①类路径靠记忆敲命令，无 `just` 配方固化，
无清理配方（`clean-out`）。

## 1. 重构项清单

约定：每项沿用项目惯例——验收示例倒推 API + 门禁全绿 + 行为不变证明。

### R0 · api_coverage 门禁修复（P0，S）

- **目标**：`just ci` 回绿。
- **改动**：`crates/ffanim/tests/api.rs` 补 table 三项使用（或由 R4 的
  data_table 示例承接，R0 先行兜底补测试）。
- **验收**：`./scripts/api_coverage.sh` exit 0。

### R1 · scenes.rs 拆分 + 样板上提（P1，M，预览器前置）

- **目标**：1285 行拆为 `scenes/` 模块目录；消除五类重复样板；为预览器
  提供可枚举、可参数化的场景库。
- **改动**：
  - `crates/ffanim-cli/src/scenes.rs` → `scenes/` 目录：按主题分组 4-5
    个文件（如 `basic.rs` / `text_formula.rs` / `annotate.rs` /
    `motion.rs` / `data.rs`）+ `mod.rs` 注册表 + `shared.rs`（上提五类
    样板：`canvas()`、`fade_title()`、`cjk_engine()` / `cjk_font()`、
    整组淡入 `show()`——text_demo:253 已有雏形）；
  - `SCENES` 常量与 `build()` 签名不变（CLI 零感知）。
- **不做**：不拆 17 个单文件（过碎）；不改任何场景的时间轴内容。
- **验收**：17 场景 `ffanim timeline --s X --json` 输出与重构前逐字段
  一致（行为不变证明）；clippy -D warnings 全绿。

### R2 · typst 装配逻辑去重（P1，S）

- **目标**：三套复制收敛到单一装配基座。
- **改动**：`crates/ffanim-typst/src/`——`formula_opts` 进 `geom.rs` 或
  engine；装配片合并 + bbox 归一化仿射抽 `assembly.rs`（delimiter/arrow/
  decimal 三方调用），对齐既有 `dbc3e05` 抽 geom.rs 的先例。
- **验收**：delimiter/arrow/decimal 三 demo 重渲，末帧像素探针与基线
  一致；55 项 typst 测试全绿。

### R3 · 画布尺寸数据驱动（P1，M，预览器前置）

- **目标**：消除 40+ 处 960/540 硬编码；预览窗口、画质预设、CLI 尺寸
  三方能一致传导。
- **改动**：场景构建签名 `(theme, fps)` → `(canvas: Canvas2D, theme,
  fps)`（`Canvas2D { w, h }` 放 ffanim-core；主题 JSON 可选 `canvas`
  字段提供默认值）；`RenderArgs` 已有隐含尺寸链路（quality 预设缩放）
  与之对齐；preview 直接复用。
- **不做**：不改默认输出尺寸（960×540 语义保留为默认 Canvas）。
- **验收**：`render --scene X` 出片与基线逐帧一致；硬编码 grep 归零
  （测试样例字面量除外）。

### R4 · examples 补充对标 manim gallery（P2，M）

- **目标**：建立「入门 → 词汇 → 公式 → 数据」梯度；顺带完成 R0。
- **新增**（命名沿 manim 主题式 snake_case）：
  | 示例 | manim 对标 | 内容 |
  |---|---|---|
  | `getting_started.rs` | `SquareToCircle` | ~15 行：矩形 create + 圆 transform + fade_out |
  | `animation_vocab.rs` | gallery 动画册 | create/uncreate/transform/fade 家族/succession 一页速览 |
  | `formula_showcase.rs` | `OpeningManimExample` | 公式排版 + t2c 着色 + match_formulas 变换 |
  | `data_table.rs` | Table gallery | 表格 lagged_start + 行高亮 + 格圈注（承接 R0 门禁） |
- **验收**：`cargo run -p ffanim --example X` 各自独立出片；api_coverage
  全绿；README 或 docs 列示例索引。

### R5 · out/ 生成流程固化（P2，S）

- **目标**：①类手工路径固化为配方，产物生命周期可管理。
- **改动**：justfile 补 `demo-all`（批量渲染 17 场景）与 `clean-out`；
  本文档 §0.2 即流程文档（维护责任随文档走）。
- **验收**：`just demo-all` 一键出全量验收片；`git status` 干净。

### R6 · preview 基础补强（P2，S，紧贴预览器开发）

- **目标**：预览器增强前建立安全网。
- **改动**：UI 底条/手柄色改走 Theme（0x22262e 等硬编码消除，alpha 派生
  与 table_demo 同族）；补 2-3 项纯逻辑测试（帧号↔秒换算、循环区间）。
- **验收**：preview 手工冒烟 + 单测绿。

## 2. 实施顺序

```
R0(门禁红,半天) → R2(typst 去重) → R1(scenes 拆分) → R3(画布参数化)
→ R4(examples 梯度) → R5(out 固化) → R6(preview 补强) → 预览器循环/seek
```

R0/R2/R1 互不阻塞可穿插；**R3 必须先于预览器开发**（预览窗口尺寸自适应
依赖 Canvas2D 传导）；R4 的 data_table 与 R0 合并执行可少走一遍。

## 3. 总验收标准

1. `just ci` 全绿（fmt + clippy -D warnings + test + api_coverage）；
2. 行为不变证明：17 场景 `timeline --json` 与基线逐字段一致 + 关键 demo
   末帧像素探针一致；
3. 960/540 与主题色反例 grep 归零；
4. examples ≥ 6 个且各自独立出片，形成入门梯度；
5. out/ 产物路径全部有 just 配方或文档锚点。

## 4. 明确不做（防蔓延）

- 不引入新依赖；不动两阶段时间轴模型与编译期求值架构；
- 不为拆而拆：eval.rs 965 行职责单一，保持现状；
- CLI 依赖 7 内部 crate 属编排层合理设计，仅补架构注释说明，不改依赖结构。
